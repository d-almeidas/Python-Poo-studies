## Sobre

Este repositório documenta meus estudos de **Programação Orientada a Objetos (POO)** em Python. Contém exemplos, exercícios e projetos criados ao longo da minha jornada de aprendizado, cobrindo tanto os conceitos fundamentais quanto suas aplicações práticas.

---

## Tópicos Estudados

### Fundamentos de POO

* Classes e Objetos
* Atributos e Métodos
* Construtores (`__init__`)
* Herança
* Encapsulamento
* Polimorfismo
* Abstração
* Classes Abstratas (`ABC`, `@abstractmethod`)

### Conceitos Avançados

* Class Methods e Static Methods (`@classmethod`, `@staticmethod`)
* Properties (`@property`, getters e setters)
* Métodos Mágicos/Dunder (`__str__`, `__repr__`, `__eq__`, etc.)
* Composição
* Herança Múltipla
