# Python Object-Oriented Programming 🏛️

## About

This repository documents my studies in **Object-Oriented Programming (OOP)** using Python. It contains examples, exercises, and projects created throughout my learning journey, covering both the fundamental concepts and their practical applications.

---

## Topics Studied

### OOP Fundamentals

* Classes and Objects
* Attributes and Methods
* Constructors (`__init__`)
* Inheritance
* Encapsulation
* Polymorphism
* Abstraction
* Abstract Classes (`ABC`, `@abstractmethod`)

### Advanced Concepts

* Class Methods and Static Methods (`@classmethod`, `@staticmethod`)
* Properties (`@property`, getters and setters)
* Magic/Dunder Methods (`__str__`, `__repr__`, `__eq__`, etc.)
* Composition
* Multiple Inheritance
